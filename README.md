# Mischungsverhältnis

Lack-Mischrechner für Lack, Verdünnung, Härter und eine optionale 4. Komponente.

- Volumetrisch (ml) oder gravimetrisch (g)
- Angabe in Prozent oder in Teilen (z. B. 100 : 15 oder 2 : 1)
- Messbecher-Grafik mit farbigen Anteilen und „Füllen bis“-Werten
- Umrechnung auf eine gewünschte Gesamtmenge (z. B. genau 1 Liter)
- Hilfe über F1 bzw. „?“
- Als App auf dem Home-Bildschirm installierbar, funktioniert auch offline

## Als App aufs iPhone
Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
